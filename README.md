# Blinking ASCII Eye

Colored terminal ASCII art with a blinking eye.

## Run

1. Install [Python 3](https://www.python.org/downloads/) (Windows: tick "Add Python to PATH").
2. Download this repo and open a terminal in the folder.
3. Run:

```
pip install -r requirements.txt
python D.py
```

Mac/Linux: use `pip3` and `python3`.

## Notes

- Maximize the terminal first.
- Press `Ctrl+C` to stop.
- Keep `mike.jpg` next to `D.py`.
- Needs a 24-bit color terminal (Windows Terminal, iTerm2, most Linux terminals).
